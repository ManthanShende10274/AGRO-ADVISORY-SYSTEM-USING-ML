Featured Project

Agro Advisory System using ML — a futuristic smart farming tool built with Machine Learning and Flask. This system detects crop diseases from images and provides real-time, weather-based farming advice tailored for Indian farmers. Designed with a user-first approach and rooted in real-world needs, it empowers the backbone of our country — the farmers.
